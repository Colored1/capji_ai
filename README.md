# CAPJI AI — كابجي

تطبيق دردشة ذكاء اصطناعي لأندرويد ببايثون (Flet) من تطوير أحمد الارحبي.

- النماذج: Gemini • Ollama Cloud (DeepSeek, Qwen, gpt-oss, Kimi...) • Claude (اختياري)
- اختيار النموذج يدوياً أو «تلقائي» مع بديل عند الفشل
- رفع صور وPDF وملفات نصية
- شاشة افتتاحية متحركة، حركات ناعمة، وشاشة «عن المطوّر»

## التشغيل على الكمبيوتر
```
py -3.13 -m pip install flet flet-cli flet-desktop
py -3.13 main.py
```
عند أول تشغيل افتح الإعدادات، الصق مفاتيحك، اضغط «تحديث قائمة النماذج» ثم «حفظ».

## إنتاج APK بدون تثبيت أي شيء على جهازك (GitHub)
1. أنشئ حساباً في github.com، ثم New repository (اجعله Private).
2. اضغط «uploading an existing file» وارفع **كل محتويات المجلد** (بما فيه مجلد `.github` و`assets`).
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
4. بعد 10–20 دقيقة افتح التشغيل المكتمل ونزّل **capji-ai-apk** من الأسفل، فك الضغط وستجد ملف APK.
5. انقله للهاتف وثبّته (اسمح بالتثبيت من مصدر غير معروف).

## تعديل معلوماتك
كل بياناتك (الاسم، الإنستغرام، الرقم، البريد، المدينة) في أعلى `main.py` داخل `DEV`.
اسم التطبيق في `APP_NAME`. الشعار في `assets/logo.png` وأيقونة التطبيق `assets/icon.png`.

المفاتيح يدخلها كل مستخدم بنفسه وتُحفظ على هاتفه فقط. لا تضع مفاتيحك داخل الكود أبداً.
